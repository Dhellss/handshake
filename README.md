# handshake

A signal flashes across nine nodes. Then the whole board turns a quarter, and you repeat it.

## Play

Open `index.html` in a browser. No build step, no dependencies.

## Rules

- The nodes are blank, so the only thing that moves is the board.
- The notch in the corner tells you which way it turned.
- Repeat the same nodes in their new places. Three lives.

## Built with

Plain HTML, CSS and JavaScript.
